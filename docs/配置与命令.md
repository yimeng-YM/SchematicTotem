# 配置与命令

[返回项目首页](../README.md)

所有 `/totemmodel` 命令均在客户端执行。设置保存于游戏实例的 `config/schematictotem.json`，图形界面与命令修改同一份配置。

## 配置界面

运行 `/totemmodel gui`、使用 Mod Menu 配置按钮或配置界面快捷键打开设置。

| 页面 | 设置范围 |
|---|---|
| 模型 | 当前投影的文件、正面朝向、旋转、尺寸、精细度和居中 / 底部站立 |
| 姿势 | 各显示场景的旋转、平移、缩放及左右手同步；由所有投影共用 |
| 常规 | 模组开关、其他实体、全局面数预算、远处细节、内部面剔除、特殊方块和颜色 |

三维预览提供物品栏、展示框、触发动画和掉落物模式；拖动旋转、滚轮缩放、双击复位。在世界中打开时，可切换第一 / 第三人称视角并查看手持效果。

「正面朝向」的自动模式根据投影形状和表面特征选择朝向；结果不符合预期时可手动指定。

## 文件与基本控制

| 命令 | 作用 |
|---|---|
| `/totemmodel` 或 `/totemmodel info` | 查看当前投影、尺寸、面数、朝向和设置 |
| `/totemmodel gui` | 打开配置界面 |
| `/totemmodel list` | 列出可用投影 |
| `/totemmodel load <文件>` | 加载投影；支持 `schematics/` 文件名、Tab 补全和绝对路径 |
| `/totemmodel clear` | 清除默认投影，保留自定义名称绑定 |
| `/totemmodel on` / `/totemmodel off` | 开启 / 关闭替换 |
| `/totemmodel reload` | 重新读取配置和投影 |
| `/totemmodel folder` | 打开 `schematics/` 目录 |

## 模型与细节

| 命令 | 作用 |
|---|---|
| `/totemmodel front <auto/south/west/north/east/up/down>` | 设置当前投影的正面朝向 |
| `/totemmodel turn <左右> [前后] [侧向]` | 设置附加旋转，单位为度 |
| `/totemmodel size <倍数>` | 调整手持、展示框和掉落物的尺寸 |
| `/totemmodel anchor <center/bottom>` | 居中或以模型底部为基准 |
| `/totemmodel detail <auto/面数/full>` | 使用全局预算、自定义预算或 1:1 完全还原 |
| `/totemmodel budget <面数>` | 设置全局面数预算，默认 8000 |
| `/totemmodel interior <true/false>` | 开关封闭内部面剔除 |
| `/totemmodel blockentities <true/false>` | 开关受支持的箱子、床、告示牌等特殊方块显示 |
| `/totemmodel biome <群系>` | 设置草、树叶、水等采用的群系颜色 |
| `/totemmodel others <true/false>` | 控制其他玩家或实体手持物品的替换；展示框和掉落物独立处理 |

`detail full` 在最高细节级保留方块原始比例，不进行重采样。若最高级超过 100 万面或 1 亿格，则退回可容纳的精度。完全还原的生成保护与文件读取时的 `maxCells` 限制属于不同检查。

示例：

```text
/totemmodel load house.litematic
/totemmodel front south
/totemmodel detail 2000
/totemmodel size 0.8
```

## 姿势

| 命令 | 作用 |
|---|---|
| `/totemmodel pose <场景> rotation <x> <y> <z>` | 设置旋转，单位为度 |
| `/totemmodel pose <场景> translation <x> <y> <z>` | 设置平移，单位为 1/16 格 |
| `/totemmodel pose <场景> scale <倍数>` | 设置缩放 |
| `/totemmodel pose <场景> reset` | 恢复默认姿势 |

场景标识：

| 标识 | 场景 |
|---|---|
| `gui` | 物品栏 / 快捷栏 |
| `firstperson_right` / `firstperson_left` | 第一人称右手 / 左手 |
| `firstperson_mod_right` / `firstperson_mod_left` | 第一人称渲染通道中的模组右手 / 左手姿势 |
| `thirdperson_right` / `thirdperson_left` | 第三人称右手 / 左手 |
| `ground` | 掉落物 |
| `fixed` | 展示框 |
| `totem_pop` | 图腾触发动画 |
| `head` | 头部 |
| `on_shelf` | 展示架；仅在提供对应功能的游戏版本中使用 |

接管第一人称手臂的模组可能通过第三人称物品上下文绘制手持物品。本模组在第一人称渲染通道中检测这种上下文，并使用 `firstperson_mod_*` 姿势；适配效果取决于第三方模组实际使用的渲染路径。

## 自定义名称绑定

```text
/totemmodel name "模型A" house.litematic
/totemmodel unname "模型A"
```

`name` 为自定义物品名绑定投影；在铁砧中使用相同名称后，该图腾可显示绑定的模型。`unname` 移除该绑定。

## 手动修改配置

编辑 `config/schematictotem.json` 后使用 `/totemmodel reload` 重新载入。建议在修改前备份配置，并优先通过图形界面或命令调整数值。模型设置按投影路径保存，姿势设置由所有投影共用。
